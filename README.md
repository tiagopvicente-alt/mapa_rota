# Rota da Energia — Mapa de municípios

Plugin WordPress em `rota-energia-mapa/`. A página `index.html` é uma demonstração estática do mapa, publicada no Render através de `render.yaml`.

No WordPress, instala a pasta `rota-energia-mapa` como plugin e usa o widget "Mapa da Rota da Energia" do Elementor ou o shortcode `[rota_energia_mapa]`.
